## §2 数据交叉比对表（指令 10 第 2 条）

**做法**：抽样 **10 个**日期／事件，与紫金山天文台公开历表逐条比对，差值记入下表。

**比对前必须先读的三条口径（否则比对本身无意义）**

1. 紫金山公开历表通常**只到「分钟」**，比对精度的上限就是 1 分钟；本模块输出也截到分钟后再比。
2. 紫金山历表口径为**东经 120° 标准时（北京时间）**；本模块默认观测地为**揭阳（约东经 116.4°）**，其**地方真太阳时**与东经 120° 标准时存在**经度差**（每 1° ≈ 4 分钟，约 14.4 分钟量级）。
3. 因此比对须**区分时刻口径**：
   - **升落类**（日出日落、月出月落、晨昏蒙影）—— 必须**同地同口径**才可比。与紫金山历表比对时，须先把本模块观测地改为紫金山同址（或把紫金山值换算到揭阳），否则 14 分钟量级的差是口径差，**不是计算误差**。
   - **节气类**（二十四节气交节时刻）—— 属**全球同一时刻**的几何事件，可直接比对，无需换算。

| 抽样编号 | 日期或事件 | 本模块输出（北京时） | 紫金山公布值 | 差值（分钟） | 是否 ≤1 分钟 | 备注（口径：升落／节气／其他） |
|---|---|---|---|---|---|---|
| S-01 |  |  |  |  |  |  |
| S-02 |  |  |  |  |  |  |
| S-03 |  |  |  |  |  |  |
| S-04 |  |  |  |  |  |  |
| S-05 |  |  |  |  |  |  |
| S-06 |  |  |  |  |  |  |
| S-07 |  |  |  |  |  |  |
| S-08 |  |  |  |  |  |  |
| S-09 |  |  |  |  |  |  |
| S-10 |  |  |  |  |  |  |

**判定规则**

- 节气类抽样全部 ≤1 分钟 → 通过。
- 升落类若未做同地同口径换算，**不得**据此判定不通过；须先换算再看差值。
- 抽样中若含 `method=analytic_meeus` 的条目，其预期为「给区间而非唯一时刻」，比对判据改为「紫金山值落在本模块给出的最早—最晚区间内」。
